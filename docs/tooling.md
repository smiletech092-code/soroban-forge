# Recommended Tooling

- **Rust**: `rustup`, `cargo`, `rustfmt`, `clippy`
- **Soroban**: `soroban-cli`, `stellar-cli`
- **JS**: `@stellar/stellar-sdk`
- **Testing**: `soroban-sdk` testutils feature
- **CI**: GitHub Actions
- **Changelog**: [`git-cliff`](https://git-cliff.org) — generates a
  [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)-compliant
  `CHANGELOG.md` from [Conventional Commits](https://www.conventionalcommits.org).
  See [Generating the CHANGELOG](changelog.md) for setup and usage.
